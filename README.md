# PopX Account Management UI

This is a React-based single-page application for user onboarding and profile management, designed as a demo for PopX. The app supports:

- Account Creation
- User Login
- Profile/Account Settings Display

## ✨ Features

- React functional components
- Simple routing using conditional rendering (no external routing libraries)
- State management using `useState`
- Clean and modern UI
